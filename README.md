# vitaltracker
Web App for Vital Tracker using HTML, CSS, Python, Flask, and SQLite

vitaltracker/
├─ app.py
├─ init_database.py
└─ templates/
    ├─ index.html
    ├─ home.html
    ├─ ekg.html
    ├─ hr.html
    └─ temp.html
└─ static/
    ├─ script.js
    └─ style.css


Download Git (https://git-scm.com/install/windows).
Download and open Visual Studio Code.
Open or create a folder to save the files to.
Open a terminal and run the following:
    git clone https://github.com/maddienicolej/vitaltracker.git

OR

Navigate to Vital Tracker Repo and download the zip folder ( located under <>Code )

After accessing files, open the terminal and run the following:
    python init_database.py
    python app.py

A session id should be given in the terminal (ex: 127.0.0.1:5000), click this link to access the web app.
